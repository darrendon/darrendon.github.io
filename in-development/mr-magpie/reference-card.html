Baubles

how each set scores
Fewest acorns at the first snow doesn’t make it through winter.

Each treasure

Mr. Magpie keeps every acorn
  1. New row. The oldest bauble leaves; deal the row back up to 8. Turn up a treasure. The last winner starts.
  2. Offer or pass. Beat the top offering with acorn cards, or pass. Pass with nothing offered: draw from the acorn deck.
  3. Drop out. Take one bauble for each acorn card you offered. You must take them all.
  4. Last one in wins the treasure and takes no baubles.
  5. Nobody offered? It waits for the next winner.
  6. Frost: everyone offers in secret. Biggest wins; ties offer again. The 4th frost ends the game.
